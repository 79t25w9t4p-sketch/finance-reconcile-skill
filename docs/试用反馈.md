# 它是否减少了你原来的操作

请实际执行这类核对工作的人试用。可以只记录在自己的本地笔记里，不必公开。未计时或未尝试的项目直接写“未记录”或“未试”。

## 首次使用，先回答四件事

1. 两份表分别做什么？你原来怎么核对，是否已有模板？只描述用途和列名。
2. 从提供文件到拿到结果，卡在哪一步？获取、环境、确认、运行或看结果均可；提供错误描述即可。
3. 结果能否直接用于核实？拿到后仍需要手动改列、抄数据或整理哪些内容？
4. 下次是否愿意继续用，原因是什么？

需要比较耗时时，原流程和工具流程要完成同一范围任务，包含准备、修表、确认、核对和整理收尾；首次安装成本单独记录并保留在总成本中。不把脚本运行时间当整个工作时间，也不根据模拟条数推算节省比例。

## 有第二批明细时再验证复用

仅用于同一业务范围、编号作用域一致的更新明细，使用自己已填写意见的上次复核工作簿。

记录是否能独立完成、是否仍要重复说明字段或搬意见、旧未解决事项是否遗漏、下次是否愿意主动再用。没有第二批任务就不必为了反馈再跑模拟示例。
