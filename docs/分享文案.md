# 两份客户明细核对：分享草稿

本稿未发布。面向已在用本地Agent、需要反复比较固定格式客户明细的人。仅展示当前实现，不承诺实际节省时长。

## 标题

**两份客户明细要核对？先试试把差异整理成这张清单。**

## 文章草稿

我用AI协助做了一个客户明细核对Skill。双方有共同业务单号、金额口径可以确认时，交两份Excel，确认对应方式，就能生成内部复核表和待核实跟进清单。

配图是虚构示例：SH-002两边差50.00，还有单边记录、重复编号和缺失金额。清单保留来源行，方便回原表核实；不会直接判断谁记错了账。

已经在用能读写本地文件、执行Python的Agent，可以拿自己的两份明细直接试，不必先跑演示。还没文件则先看模拟结果。首次需要Python和openpyxl；普通聊天窗口不能直接执行。

反复换表时，现有版本支持保存规则、沿用未变化的旧意见、突出新增和变化事项。收到反馈后仍需把确认结果填回内部表；当前不自动核销或导入反馈。

项目在GitHub，目前没有真实用户节省时间的测量。更想知道你原来怎么做、卡在哪一步、结果还要手动补什么，以及下次愿不愿意再用。

项目：https://github.com/79t25w9t4p-sketch/finance-reconcile-skill

## 视频演示顺序

给两份虚构明细 → 展示已确认的共同编号和金额列 → 打开跟进清单 → 按来源行回查SH-002。使用已准备的环境时注明“环境已准备”；加速片段注明“过程已加速”。

配图使用[月末虚构示例](../examples/月末客户对账/说明.md)。全程标模拟数据，不使用真实客户资料、伪造评价或未经测量的节省比例。
