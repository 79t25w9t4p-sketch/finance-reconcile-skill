# 基础对账助手 · finance-reconcile

**每个月还在复制粘贴、拉公式对账？交两份明细，自动整理差异，拿到可复核的 Excel。**

为反复核对台账的**出纳、应收应付会计和财务助理**准备。第一次确认核对方式，以后换表重跑；让工具接手精确匹配、筛选差异、汇总和整理清单，你集中处理例外。

[先看 Excel 产物](examples/重跑复核示例.xlsx) · [看一次完整使用过程](examples/使用体验.md) · [开始使用](#开始使用)

> 适用前提：两份表有能对应的业务单号，期间、币种、金额含义和明细粒度一致。当前是 v0.6.0 初版。下面的展示均为虚构数据，不代表真实用户案例或节省时间统计。

## 最适合谁、什么工作

| 你在做的事 | 交给它的两份表 | 得到的结果 |
|---|---|---|
| 应收会计核对逐笔回款记录 | 按同一单据口径整理的应收/回款明细 | 金额差异、单边记录、重复记录 |
| 应付会计核对付款登记 | 供应商付款台账与有对应业务单号的系统导出 | 可回查来源行的差异清单 |
| 出纳、财务助理核对导出数据 | 同一范围的业务台账与另一套系统明细 | 完整记录核对、异常整理及复核 Excel |

分批回款、合并付款、没有共同单号的银行流水，目前会留给人确认关系；“金额差不多”不会被自动当成已对上。

## 你怎么用

第一次，把两份表的本地路径交给装好技能的 AI：

> 帮我核对这两份明细。先给我建议的核对方式，确认后输出待处理清单，并记住这次规则。

助手会先提出字段建议，例如：

> 建议按“客户＋订单号”对应，比较左表的应收金额与右表的回款金额；两表同一期间、币种、逐单口径确认后，就能运行。

列名存在歧义时，只补问需要确定的项。你已经说清的条件会直接采用。执行后交付：

```mermaid
flowchart LR
    A[两份 Excel / CSV] --> B[首次建议字段并确认口径]
    B --> C[自动匹配并整理异常]
    C --> D[可填写意见的复核 Excel]
    D --> E[换新表 · 按保存规则重跑]
    E --> C
```

下次说：

> 按上次的方式核对这两份新表，沿用这份上次结果里的处理意见。

字段映射、工作表和表头位置都可以复用；格式变了才提示你重新确认。

## 打开结果就能继续干活

| 工作表 | 打开后做什么 |
|---|---|
| **汇总** | 先看本次待办、需重新复核、新增待办、意见沿用数 |
| **待处理** | 优先查看变化和新增事项，核对原金额与来源行，在黄色列填写状态和意见 |
| **已匹配** | 查看当前按指定规则一致的记录，必要时抽查 |
| **历史记录** | 查看上次有、本次没出现的事项；没出现不等于已解决 |

例：先前已处理过三笔，再换表重跑，会得到这样的结果。以下来自仓库可复现的[重跑示例](examples/重跑复核示例.xlsx)：

| 记录 | 这次发生了什么 | 输出如何处理 |
|---|---|---|
| A | 内容没变，只换了行序 | 保留“已解决”与原意见 |
| B | 金额变化 | 留下旧意见，标成“需重新复核” |
| D | 新出现的差异 | 标记“新增”，等待处理 |
| C | 本次没有出现 | 留在历史记录，保留原意见 |

汇总数字是生成时的统计，手动修改处理状态后不会实时更新，下次重跑会重新统计。

你少做的是：反复选择匹配列、拉查找公式、筛出差异、整理异常表、搬运已经填过的意见。业务判断仍由你做。

## 开始使用

这是装进支持本地脚本的 AI 助手中的 **Skill**；当前提供 Codex 使用方式。不是上传网页，单独下载一个 `SKILL.md` 也不能运行，需保留整个目录。

1. 从仓库右上角 **Code → Download ZIP** 下载并解压。
2. 将完整目录放到 `~/.codex/skills/finance-reconcile/`，确认该目录内直接有 `SKILL.md` 和 `scripts/`。
3. 使用已有的 Node.js 18+、Python 3.9+ 环境。Python 需要 `openpyxl`；没有时在该 Python 环境运行 `python3 -m pip install -r requirements.txt`。
4. 新开一个 Codex 会话，用上面的自然语言调用；也可直接点名 `$finance-reconcile`。

安装需要一次准备，日常核对无需自己拼命令。项目代码为 MIT 开源许可；AI 宿主及其运行环境另行准备。真实财务文件保存在本地工作目录，不提交进公开仓库。

## 使用范围

- 支持 UTF-8 CSV/TSV、XLSX，最多5000条明细、50列；旧xls先另存，公式单元格先重算并导出值。
- 常见列名识别只给建议。多个金额列、不同客户标识、未知列名会要求确认，不自行凑匹配。
- 支持“公司/客户＋单号”联合匹配；空编号、重复编号和异常金额保留为问题。
- 金额精确到分，不把缺失金额当零；Excel输出金额为精确文本，便于核对和避免长数字失真。
- 只沿用内容未变化的意见。空编号不继承，重复键仍需复核；历史条目重新出现按新增处理。
- 保留Excel表头及隐藏标识列，处理意见填写文本。脚本本地计算；AI对话本身的数据处理由宿主决定。
