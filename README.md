# 客户对账助手 · finance-reconcile

**客户发来一份 Excel，说金额对不上。先帮你找出该核实的几笔。**

给刚开始独立负责客户月末对账、不会写代码的商贸公司财务助理准备。把我方明细与客户明细交给本地 AI 助手，确认对应方式，得到**内部复核表＋待核实跟进清单**。下次换表时复用规则，内容没变的处理意见可以沿用。

[复制给 Agent 开始使用](#复制这段话交给-codex) · [先看输出](examples/月末客户对账/跟进清单.xlsx) · [新手教程](docs/新手第一次使用.md)

> 当前 v0.7.0，提供 Codex 本地使用流程，需要一次环境准备。演示均为虚构数据；尚无真实用户节省时间的测量。适合的是有共同单号、同一金额口径的明细核对。

## 先确认：是不是你正在做的这件事

| 你的情况 | 从这里开始 |
|---|---|
| 月末收到某个客户的采购/结算明细，要和我方销售/结算明细核对 | 这是首个演示场景 |
| 双方都有同一个送货单号；同一客户、期间、币种、含税口径，每张单一行 | 可以先建议字段，再确认后核对 |
| 一单多种商品，明细粒度不同；两边只有各自系统单号 | 先确认共同标识和粒度，不能仅按相近金额配对 |
| 要把多笔回款与一张发票核销，或处理无共同编号的银行流水 | 当前不提供自动关系匹配 |

客户表中的“供应商”可能指我方，不能直接与我方表中的“客户”相配。双方自有客户编码、内部订单号也未必共通。助手会要求确认这些对应关系。

## 它具体替你做哪几步

| 以前重复做的事 | 这次拿到的结果 |
|---|---|
| 找匹配列、拉查找公式、逐项比金额 | 按确认的业务编号精确核对 |
| 筛出金额差异、单边、重复及异常值 | 保留来源行的内部复核 Excel |
| 重新抄一份异常清单去跟进 | 独立的跟进清单，带建议核实事项和反馈空栏 |
| 换表后重做规则、搬上次处理意见 | 复用配置；内容变化的条目要求重新复核 |

金额不同不代表客户错账；重复单号可能是一单多行。工具整理线索，你核实事实。

## 一次具体演示

虚构场景：同一客户、2026年9月、人民币、双方逐送货单比较含税金额。我方8行、客户7行，共8个编号组；3组金额一致，5组待核实。重复组的每条原记录都保留。

| 单号 | 发现什么 | 清单建议核实什么 |
|---|---|---|
| SH-002 | 我方2350.00，客户2300.00 | 差额50.00，核对计价、含税口径及调整 |
| SH-004 | 只在我方出现 | 客户是否遗漏、跨期，或编号不同 |
| SH-005 | 我方出现两次 | 是重复登记还是一单多行，不能直接删除 |
| SH-006 | 我方金额缺失 | 补齐金额，不能按零处理 |
| SH-008 | 只在客户出现 | 我方是否遗漏、跨期，或编号不同 |

下载 [我方示例](examples/月末客户对账/模拟_我方销售明细.xlsx)、[客户示例](examples/月末客户对账/模拟_客户采购明细.xlsx)、[内部复核结果](examples/月末客户对账/复核工作簿.xlsx)、[跟进清单](examples/月末客户对账/跟进清单.xlsx)。可以先看这些文件，再决定是否准备运行环境。

### 安装后，直接说要做什么

用户技能目录内应直接包含 `SKILL.md`、`scripts/` 和 `examples/`。Windows 对应用户目录下的 `.agents\skills\finance-reconcile`。技能未被发现时检查层级，再按[官方本地技能目录说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)处理。

> 使用 $finance-reconcile。左表是我方明细，右表是客户发来的明细。这次只核对同一客户、2026年9月、人民币的逐单含税金额。请先建议共同单号和金额列，确认后给我复核表与跟进清单，并保存规则。

下次换表：

> 按上次确认的方式核对这两份新明细；沿用我填写过的上次复核工作簿里的处理意见。结果存到新目录。

有多个旧配置时只确认用哪一个；格式发生变化时重新确认。

## 打开结果后做什么

- **复核工作簿.xlsx**：先看“汇总”，再到“待处理”的黄色列填写状态与内部意见；“已匹配”可抽查，“历史记录”保留本次未出现项。
- **跟进清单.xlsx**：查看“待核实事项”，包含生成时待处理、处理中、需重新复核项，不带内部意见、隐藏标识或已解决记录。分享前检查客户、期间、币种及收件范围；它仍含业务编号和金额。

两个文件都是生成时快照；手动改内部处理状态不会实时更新跟进清单和汇总。需要更新时重跑。跟进反馈需整理回内部复核表黄色列，当前没有自动导入反馈功能。

## 使用边界

- 需要 Node.js 18+、Python 3.9+、`openpyxl>=3.1,<4`；`scripts/doctor.py` 只检查现有环境。
- 支持UTF-8 CSV/TSV、XLSX，最多5000条明细、50列。旧xls先另存，公式先在原软件重算并导出值。
- 根据表头建议字段；多个金额列、未知列名和不对应的客户范围需要确认。不能只因“含税金额”同名就认定口径一致。
- 保留重复、空编号、无效金额；不做模糊匹配、自动合并或跨行求和。金额精确到分，输出金额为精确文本。
- 内容未变化才沿用意见；重复键始终复核，空编号不继承。本次未出现不等于已解决。
- 脚本本地计算，真实文件不提交公开仓库。AI对话本身的数据处理由宿主决定；默认只把摘要交给模型。
